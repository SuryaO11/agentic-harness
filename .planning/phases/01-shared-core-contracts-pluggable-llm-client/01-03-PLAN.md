# Plan 01-03: Contract & Client Verification Suite

## Objective
Implement comprehensive unit tests verifying that all shared core contracts are structurally sound and immutable, the `LLMClient` strictly enforces temperature 0.0 and `max_retries=0`, provider switching operates seamlessly, and `RateLimitError` correctly extracts the `retry-after` header.

<threat_model>
- **Threat**: Regressions in contract schemas or transport retry configurations breaking downstream phases.
- **ASVS Level**: 1 (Automated security & regression tests)
- **Mitigation**: Automated pytest suite running in isolated environments with mock responses to prevent accidental live token consumption.
</threat_model>
