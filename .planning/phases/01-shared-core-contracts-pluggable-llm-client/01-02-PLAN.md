# Plan 01-02: Pluggable LLM Client Implementation

## Objective
Implement the pluggable `LLMClient` abstract interface and provider adapters (Groq and Ollama) with strict enforcement of `max_retries=0`, fixed temperature (0.0), configurable model selection (defaulting to `openai/gpt-oss-20b`), and 429 `retry-after` header extraction.

<threat_model>
- **Threat**: Silent retry duplication multiplying inference costs, API key exposure, or rate-limit lockouts.
- **ASVS Level**: 1 (Cryptographic & Credential storage, resource exhaustion mitigation)
- **Mitigation**: Pass `max_retries=0` to SDK HTTP transports; read API keys strictly from environment variables without logging secrets.
</threat_model>
