# Plan 01-01: Shared Core Contracts & Type Definitions

## Objective
Establish the foundational data contracts, enums, and exception hierarchy that all downstream validation, critic, retry, and caching subsystems depend upon. These interfaces are locked and immutable.

<threat_model>
- **Threat**: Malformed or unvalidated input structures passing through contracts, causing silent downstream failure or unexpected type coercion.
- **ASVS Level**: 1 (Input validation & integrity)
- **Mitigation**: Use Pydantic v2 with strict validation and frozen schemas where immutability is required.
</threat_model>
